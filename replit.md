# Project: Empty Node.js App

## Overview
A minimal, empty full-stack Node.js project.
- Frontend: React with Tailwind CSS and Framer Motion. Clean minimal style.
- Backend: Express API.
- Shared: Zod for schema validation.
- Database: None configured yet.

## Architecture
- `client/`: Frontend React application.
- `server/`: Backend Express server.
- `shared/`: Shared types and API contracts.

## API Contracts
- `GET /api/health`: Basic health check endpoint.
